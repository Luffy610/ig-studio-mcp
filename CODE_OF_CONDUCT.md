# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

In short: be welcoming, be respectful, assume good intent, and focus on what is best for the community. Harassment, personal attacks and publishing other people's private information are not tolerated.

## Reporting

If someone's behaviour in this project's issues, pull requests or discussions breaks the code of conduct, contact the maintainer, [@Luffy610](https://github.com/Luffy610), through GitHub. You can also use GitHub's [report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) feature. Reports are handled privately.

The maintainer may remove, edit or reject comments, commits, code, issues and other contributions that don't follow this code of conduct. They may also temporarily or permanently block contributors whose behaviour is inappropriate, threatening or harmful.
